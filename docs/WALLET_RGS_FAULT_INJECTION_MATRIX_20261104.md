## Boundary

- Verified: deterministic local SQLite transaction/recovery/idempotency/fencing/replay/tamper behavior covered by the tests above.
- Not verified: multi-host lease consistency, distributed fencing, network partitions, Provider idempotency semantics, remote Wallet transaction atomicity, real-money settlement, KMS/HSM key custody or Provider-side event replay.
